# 🚀 CareerX AI

> **Your data. Your skills. Your career trajectory.**

CareerX AI is an **AI-powered career intelligence and job-readiness platform** designed to help students discover suitable career paths based on their **academic performance, skills, projects, certifications, interests, assessments, career preferences, and supporting evidence**.

Unlike a simple career recommendation system, CareerX AI provides a complete journey:

**Analyze → Recommend → Explain → Identify Gaps → Measure Readiness → Build Roadmap → Mentor Guidance → Track Progress**

---

## 📌 Overview

Students often have useful information spread across:

- Academic records
- Skills
- Projects
- Certifications
- Resume
- Interests
- Assessments
- Career preferences

However, they may not know:

- Which career best matches their current profile
- Why that career matches
- Which skills they are missing
- Which academic areas need improvement
- How ready they are for the target role
- What they should learn or build next

CareerX AI brings all these signals into a **single career intelligence platform**.

### Core Workflow

```text
Student Data
     ↓
Data Verification
     ↓
Profile Analysis
     ↓
Career Intelligence Engine
     ↓
Career Recommendation
     ↓
Skill + Academic Gap Analysis
     ↓
Job Readiness
     ↓
Personalized Career Roadmap
     ↓
Mentor Guidance
     ↓
Progress Tracking
     ↓
Continuous Re-analysis
````

# 🎯 Key Objectives

CareerX AI aims to:

1. Recommend suitable career paths for students.
2. Explain why a career matches a student's profile.
3. Analyze academic and technical gaps.
4. Measure job readiness.
5. Generate personalized career roadmaps.
6. Recommend relevant projects and certifications.
7. Provide mentor-assisted career guidance.
8. Provide institution-level analytics for administrators.
9. Maintain evidence-aware student profiles.

# ✨ Main Features

## 🎯 1. Career Recommendation

CareerX AI uses multiple student signals instead of relying only on CGPA or one skill.

### Six-Signal Career Match Model

| Signal             | Weight |
| ------------------ | -----: |
| Skills             |    35% |
| Academic Alignment |    20% |
| Projects           |    15% |
| Interests          |    15% |
| Certifications     |     8% |
| Assessments        |     7% |

### Career Match Formula

```text
Career Match Score =

0.35 × Skills
+ 0.20 × Academic Alignment
+ 0.15 × Projects
+ 0.15 × Interests
+ 0.08 × Certifications
+ 0.07 × Assessments
```

The recommendation system can also provide:

* Overall match
* Skill alignment
* Academic alignment
* Project alignment
* Interest alignment
* Certification alignment
* Assessment alignment
* Strengths
* Technical gaps
* Academic gaps

```bash
git clone https://github.com/manoranjith214/CARRIERX-AI.git

```

---

## 2. Backend Setup

```powershell
cd CareerX-AI-Backend

python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Create a `.env` file using the variables expected by the current backend configuration.

Example local configuration:

```env
SECRET_KEY=change-this-to-a-long-random-secret
DATABASE_URL=sqlite:///./careerx.db
```

Start the backend:

```powershell
python run.py
```

Backend:

```text
http://127.0.0.1:8000
```

Swagger:

```text
http://127.0.0.1:8000/docs
```

Open another terminal:

```powershell
cd CareerX-AI-Frontend

npm run dev
```

The terminal will show the Vite development URL.

# 📌 Responsible AI

CareerX AI follows responsible analysis principles:

* Do not treat anomalies as automatic proof of fraud.
* Keep verification status separate from student judgment.
* Provide explanations for recommendations.
* Do not use CGPA as the only career signal.
* Protect role-based data access.
* Do not claim guaranteed employment outcomes.
* Use real student data instead of fabricated academic values.
* Provide factual and actionable guidance.
